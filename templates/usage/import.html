How it works

  • Each row is one period of actual use, for example from a door-sensor export or a paper logbook.
  • Rows are linked automatically to the matching class or approved reservation. Rows with no match are recorded as unscheduled use.
  • All or nothing: if any row has an error, nothing is imported.
  • Rows that overlap usage already recorded for the same room are rejected as possible duplicates.
